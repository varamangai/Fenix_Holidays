# Fenix Holidays

A modern and responsive travel agency website developed using Next.js. This project showcases travel destinations, holiday packages, customer experiences, and enquiry options through a clean and user-friendly interface.

---

## Features

- Responsive Design
- Premium Travel UI
- Hero Banner
- About Section
- Popular Destinations
- Holiday Packages
- Customer Gallery
- Customer Reviews
- Contact Section
- WhatsApp Integration
- Instagram Integration
- Mobile-Friendly Navigation

---

## Tech Stack

- Next.js
- React.js
- JavaScript
- CSS Modules

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
